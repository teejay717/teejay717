### 🌟 Featured Projects

#### 🏡 Klee — Distributed Household Chore & Expense Tracker (Next.js App Router)
**[View Repository](https://github.com/teejay717/klee-chore-tracker)**

A type-safe full-stack application leveraging modern Next.js patterns to optimize shared-living household accountability and prevent database abuse.

* **Server Architecture:** Built using pure Next.js Server Actions (`actions.ts`) for unified, secure data mutations, bypassing traditional decoupled API routing configurations.
* **Database Layer:** Structured with a robust relational **PostgreSQL** schema utilizing **Drizzle ORM** for end-to-end type safety from the database to the UI components.
* **Traffic Control & Security:** Integrated an **Upstash Redis** distributed caching layer to enforce strict rate-limiting on sensitive server actions, preventing unauthorized or accidental endpoint spamming.

#### 💼 Tipid — Decoupled Budget Tracker (MERN)
**[View Repository](https://github.com/teejay717/tipid-budget-tracker)**

A comprehensive data persistence financial application tracking balances, habits, and user transactions.
* **Security:** Handled custom authentication via **JWT** tokens and bcrypt password hashing.
* **Data Visualization:** Translated complex Mongo documents into elegant, interactive dashboards with **Recharts**.
* **Deployment:** Supervised a decoupled live state environment with a React UI on Vercel connecting to an Express server hosted on Render.
